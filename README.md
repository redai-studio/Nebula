# Nebula: Distributed Position-Independent Caching for LLM Serving

Nebula is a distributed LLM serving framework built on SGLang and NVIDIA Dynamo. It enables cross-worker reuse of position-independent caches and parallel prefill for RAG and agent workloads.

**Code coming soon.** The implementation, documentation, and examples will be released in this repository.

📄 [Read the paper](https://arxiv.org/abs/2611.09474)
